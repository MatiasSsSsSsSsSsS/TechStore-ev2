# TechStore INACAP

TechStore INACAP es un sistema web desarrollado en Django para la gestión de un catálogo y inventario de productos tecnológicos. La aplicación permite visualizar productos, filtrarlos por categorías, buscar por nombre y revisar información detallada de cada artículo.

## Descripción del proyecto

El proyecto está orientado a una tienda de tecnología y cuenta con una sección pública donde cualquier usuario puede navegar el catálogo y ver las fichas de productos. Además, incluye una parte administrativa protegida por autenticación, donde el usuario administrador puede:

- Crear nuevos productos
- Editar productos existentes
- Eliminar productos desde una vista de confirmación
- Gestionar el inventario de forma ordenada y segura

## Funcionalidades principales

- Catálogo público con cards de productos
- Búsqueda por nombre
- Filtro por categorías
- Vista de detalle del producto
- CRUD completo para administración
- Login y logout de usuarios
- Diseño responsive con navbar dinámico según el estado del usuario
- Persistencia de datos con SQLite y ORM de Django

## Tecnologías utilizadas

- Python
- Django
- SQLite
- HTML + Bootstrap
- Formularios de Django

## Objetivo del sistema

El proyecto busca simular una plataforma sencilla y funcional de gestión de productos tecnológicos, combinando catálogo público con administración interna del inventario, siguiendo la lógica de un sistema web real desarrollado en Django.
